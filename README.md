# DreamHRAi - HR Management System

A modern desktop application built with Electron.js for comprehensive HR management powered by artificial intelligence.

## 🚀 Features

- **Employee Management**: Complete employee database with advanced search and filtering
- **AI Analytics Dashboard**: Deep workforce insights with predictive modeling
- **AI Recruitment**: Intelligent candidate matching and automated screening
- **Performance Tracking**: AI-powered evaluations and goal setting
- **Payroll Management**: Automated processing with compliance checks
- **Training & Development**: Personalized learning paths and skill analysis

## 🛠️ Technology Stack

- **Electron.js**: Latest version (39.2.4)
- **HTML5/CSS3**: Modern responsive UI
- **JavaScript**: ES6+ features
- **Node.js**: Backend runtime

## 📋 Prerequisites

- Node.js (v14 or higher)
- npm or yarn package manager

## 🚀 Getting Started

### Installation

1. Clone or download the project
2. Navigate to the project directory
3. Install dependencies:
   ```bash
   npm install
   ```

### Running the Application

Start the application in development mode:
```bash
npm start
```

This will launch the DreamHRAi desktop application with DevTools open for debugging.

### Building for Production

To build the application for distribution:

```bash
npm run build
```

## 🔧 Development

### Adding New Features

1. Modify `src/index.html` for UI changes
2. Update `main.js` for Electron-specific functionality
3. Add new dependencies with `npm install --save-dev`

### Customization

- **Styling**: Edit the CSS in `src/index.html`
- **Window Properties**: Modify `main.js` for window behavior
- **Icons**: Add app icons to `assets/` folder and reference in `main.js`
