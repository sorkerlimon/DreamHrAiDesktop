# Assets Directory

This folder contains application assets like icons.

## Required Files:
- `icon.ico` - Application icon (256x256 recommended) for Windows installer
- `icon.png` - Application icon for the app window

## Creating Icons:
1. Create your icon in PNG format (512x512 recommended)
2. Convert to ICO format using online tools or software like:
   - https://favicon.io/favicon-converter/
   - GIMP
   - Photoshop

## Note:
Without an icon.ico file, the build will use default Electron icon.
Add your custom icon to get a branded installer!
